# Oracle mutants

Every gated DOD point receives a deliberately broken implementation. The approved pilot set is listed under [Calibration mutations](../docs/phase-1-plan.md#calibration-mutations) in the Phase 1 plan; the campaign set in §4.5 of the [program plan](../docs/program-plan.md).

A mutant must not be used as the reference implementation, nor may its defect be chosen after inspecting an arm's result.
